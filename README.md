# 🎓 캠퍼스 설문조사 결과 분석 웹 앱 (Streamlit)

대학 학생들의 생활습관, 학교생활 만족도, 한 줄 평 텍스트를 정제 및 시각화하여 분석해주는 대시보드 웹 애플리케이션입니다.

---

## 📌 주요 기능

1. **사용자 파일 업로드 기능**
   - 웹 화면(사이드바)에서 사용자가 보유한 CSV 설문조사 파일(`campus_life.csv` 등)을 직접 업로드하여 분석합니다.
2. **결측치 및 데이터 전처리 자동 안내**
   - 수치형 데이터 자동 변환 및 결측치/오류 데이터를 정제하여 유효 데이터 건수를 안내합니다.
3. **학과별 데이터 필터링 (사이드바)**
   - 전체 학과 또는 특정 학과를 선택하여 맞춤형 시각화 분석 결과를 제공합니다.
4. **학과별 평균 생활습관 비교 (막대그래프)**
   - 공부시간, 스마트폰 사용시간, 수면시간의 학과별 평균을 비교합니다.
5. **생활시간 vs 학교생활 만족도 분석 (산점도 및 회귀선)**
   - 생활습관 항목에 따른 학생 만족도의 연관 관계를 시각적으로 확인합니다.
6. **한 줄 평 형태소 및 감성 분석**
   - **Top 10 키워드**: 자주 언급된 명사 단어 상위 10개를 막대그래프로 출력합니다.
   - **긍정/부정 감성 분석**: 키워드 기반으로 긍정 및 부정 표현 횟수와 비율을 카드로 표시합니다.
   - **워드클라우드**: 주요 단어 시각화 워드클라우드를 생성합니다.

---

## 🛠️ 실행 방법

### 1. 패키지 설치
프로젝트 루트 디렉토리에서 아래 명령어를 실행하여 필수 라이브러리를 설치합니다.

```bash
pip install -r requirements.txt
```

### 2. 앱 실행
아래 명령어로 Streamlit 앱을 실행한 후, 브라우저 화면의 왼쪽 사이드바에서 분석할 CSV 파일을 업로드합니다.

```bash
streamlit run app.py
```
